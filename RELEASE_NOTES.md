# Mülk Yönetim 1.0.7

- Kira artışından sonra geçmiş tahsilatların güncel kira üzerinden hesaplanması düzeltildi. Güncel kira ve kayıtlı tahsilat ayrı gösterilir.
- Geçmiş aya yeni ödeme girerken o dönemde alınan tutar istenir; önceki ödemenin kesintisi yeni aya taşınmaz.
- Özçam İnşaat hesabı ve tüm işlemleri Excel olarak dışa aktarma desteği eklendi.
- GitHub güncelleme indirmeleri, hata bildirimleri ve kurulum dosyası doğrulaması iyileştirildi.

Mevcut ödeme kayıtları korunur. Windows için `mulk-yonetim-setup-1.0.7.exe` dosyasını indirin veya uygulamadaki **Güncellemeleri Kontrol Et** düğmesini kullanın.
